## Get started

Choose **Code > Download ZIP**, extract the repository, and open `index.html` in a modern browser. Keep `assets/` beside the HTML file. No framework install, API key or database is required.

For an optional local HTTP preview, run this command inside the extracted folder:

```sh
python -m http.server 4210 --bind 127.0.0.1
```

Then open <http://127.0.0.1:4210/>. Python is one optional preview tool, not a dependency of the website.

## Included features

- Editable HTML, CSS and vanilla JavaScript
- Care accordion, first-visit steps and practice hours
- Responsive navigation, local fonts and licensed photography
- Honest unsent visit-request draft; no medical details collected

## Make it yours

Edit the content and metadata in `index.html`, styles in `assets/css/aster.css`, and interactive data/behaviour in `assets/js/aster.js`. Replace the demonstration identity, contact destinations and illustrative claims with your own accurate information. Preserve filenames and relative paths when replacing assets.

The visit form prepares an unsent local draft. It does not book an appointment, notify a provider or operate a patient portal. Do not enter symptoms, health records or sensitive medical information into the demonstration.

Connect your own secure backend or service if you need real submissions. Never place private credentials in frontend files.

Upload the supplied files to an ordinary static host or domain subfolder. No build command is needed. Detailed editing, hosting and fallback instructions are in [README.txt](README.txt).
